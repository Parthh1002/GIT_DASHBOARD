I'm a Computer Science undergraduate at **LDRP-ITR** and a full-stack developer focused on shipping end-to-end web applications that are **fast, secure, and genuinely useful**. I work across the entire stack — crafting clean, responsive interfaces with **Next.js**, **React.js**, **TypeScript**, and **Tailwind CSS**, and engineering reliable backend systems with **Node.js**, **Express**, **PHP**, and **RESTful APIs**.
